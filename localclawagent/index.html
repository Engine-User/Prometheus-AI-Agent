Get it running

Two ways in.

Just want to run it, install from pip. Want to read the code — which is the point of this repo — clone it instead. Every block below is copy-pasteable.

Just run it

01 install 
pip install prometheus
02 talk to it in the terminal 
# your first run tells you which key to set
prometheus
03 or open the browser cockpit 
prometheus dashboard    # → localhost:7777

Or read the code

04 clone, then install into a venv 
git clone https://github.com/Engine-User/Prometheus-AI-Agent
cd Prometheus-AI-Agent
uv venv && uv pip install -e .
cp .env.example .env    # pick a provider, paste ONE key
05 run it from the checkout 
uv run prometheus
uv run prometheus dashboard
